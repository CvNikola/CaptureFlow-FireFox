# CaptureFlow for Firefox

CaptureFlow is a browser extension project for Firefox.

> **Project status:** This repository is used to share downloadable builds and release notes. Feature descriptions and screenshots will be added as the extension is finalized.

## Download

Visit the [Releases](../../releases) page to download the latest available package.

## Installation

### Temporary installation for testing (Firefox)

If a release contains a ZIP archive with the extension files:

1. Download and extract the ZIP archive.
2. In Firefox, open `about:debugging`.
3. Select **This Firefox**.
4. Click **Load Temporary Add-on…**.
5. Select the `manifest.json` file from the extracted extension folder.

**Important:** Temporary add-ons are removed when Firefox restarts. For regular, persistent Firefox installation, the extension generally needs to be packaged and signed through Mozilla Add-ons (AMO). A ZIP intended for Chrome is not necessarily compatible with Firefox.

## Updates

New versions and release notes will appear in [Releases](../../releases). Manually installed test versions are **not** automatically updated from GitHub.

## Free and Pro

If a build offers Free and Pro features, any subscription and payment options are presented within the extension. Please refer to the extension's own interface for the current terms.

## Feedback and bug reports

Use [GitHub Issues](../../issues) to report problems or suggest improvements. When reporting a bug, include your Firefox version, extension version, and steps to reproduce it. Avoid sharing passwords, payment details, or other personal information.
